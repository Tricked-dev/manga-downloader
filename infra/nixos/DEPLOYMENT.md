# Deployment checklist

This is an immutable image-runtime system, not a normal `nixos-rebuild switch`
deployment.

## Host Values

The host config is filled in for the current VPS:

- domain: `trashcan.ing`
- provider: Netcup VPS 2000 ARM G11, Manassas
- system: `aarch64-linux`
- public IPv4: `152.53.83.190/22`
- IPv4 gateway: `152.53.80.1`
- public IPv6 prefix: `2a0a:4cc0:2000:38cb::/64`
- IPv6 gateway: `fe80::1`
- uplink MAC: `8a:74:31:f3:47:52`
- hostname: `vps-83190`
- sysupdate disk device: `/dev/vda`
- update source path: `/var/updates/`

If the disk name is different on the target, change:

```nix
infra.imageRuntime.diskDevice = "/dev/sda";
```

## Disk Model

The image-runtime layout is:

- ESP, vfat, mounted at `/boot`
- active squashfs store slot, mounted at `/nix/store`
- inactive squashfs store slot, written by sysupdate
- persistent Btrfs `/var`, mounted with `compress=zstd:3,noatime`

The Netcup ARM image uses UEFI.

`/` is tmpfs and cleared on reboot. Persistent state must live under `/var`.

## Secrets

Secrets are deployed from the encrypted SOPS file committed with the flake:

```text
infra/nixos/secrets/vps-83190.yaml
```

Do not copy plaintext `.env` files or an out-of-band
`/var/lib/infra-secrets/vps-83190.yaml` to the host. Services consume only the
runtime paths generated by sops-nix.

Expected keys:

```yaml
manga-downloader.env: |
  BACKEND_API_KEY=change-me
grafana.env: |
  GF_SECURITY_ADMIN_PASSWORD=change-me
  GF_SECURITY_SECRET_KEY=change-me-32-byte-random-value
  GF_AUTH_GENERIC_OAUTH_CLIENT_SECRET=change-me
```

sops-nix uses `/var/lib/sops-nix/key.txt` as the target's private age identity.
It is generated on first boot if missing, but the committed SOPS file must be
encrypted for that matching public key before `sops-install-secrets.service` can
decrypt it. After updating secret recipients, deploy by building a normal
sysupdate bundle from Git and starting `systemd-sysupdate.service`.

## Tailscale

Tailscale is enabled without a baked auth key. Enroll it manually after first boot.

Configured flags:

```sh
--ssh=false --accept-routes=false --accept-dns=false --shields-up=false
```

## Public Ingress

Ferron serves the public origin behind Cloudflare. DNS should point at the VPS
and stay proxied:

```text
trashcan.ing          A 152.53.83.190
*.trashcan.ing        A 152.53.83.190
```

Cloudflare Tunnel, Cloudflare Access, WARP, and the old mesh address are not
used for public ingress.

Ferron uses HTTP-01 for origin certificate issuance because TLS-ALPN-01 cannot
pass through Cloudflare TLS termination. At minimum the configured public names
are:

```text
auth.trashcan.ing
grafana.trashcan.ing
manga-api.trashcan.ing
```

## Build And Update

Validate:

```sh
nix flake check --all-systems --no-build path:/Users/samuel/Projects/manga-downloader/infra/nixos
```

Build and deploy a sysupdate bundle that includes the repo's Bazel-built manga
service:

```sh
cd /Users/samuel/Projects/manga-downloader/infra/nixos
TARGET_HOST=vps-83190 ./scripts/build-bazel-sysupdate.sh
```

`scripts/sysupdate-lifecycle.sh` is the implementation entrypoint behind the
compatibility scripts. It owns artifact resolution, image-runtime output builds,
bundle packaging, upload, and starting `systemd-sysupdate.service`.
Bundle and provider-image names come from the image-runtime slot identity module,
so repart, sysupdate, and packaging use the same generated facts.

Build the image/sysupdate output without refreshing the Bazel service artifact:

```sh
cd /Users/samuel/Projects/manga-downloader/infra/nixos
UPDATE_FLAKE=false ./scripts/build-sysupdate.nu
```

Build the custom VPS provider image:

```sh
cd /Users/samuel/Projects/manga-downloader
nix develop ./infra/nixos --command nu ./infra/nixos/scripts/build-provider-image.nu
```

The provider artifact is:

```text
result-provider-qcow2/vps-83190-provider-v<version>.qcow2
```

It is a UEFI image using `BOOTAA64.EFI`.

The sysupdate module expects compressed artifacts in:

```text
/var/updates/
```

Then run on the target:

```sh
systemctl start systemd-sysupdate.service
systemctl reboot
```

The sysupdate switch path updates the UKI and the inactive store slot. That is
the expected path on the Netcup ARM VPS.
